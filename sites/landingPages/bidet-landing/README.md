# SensPa Bidet Landing Page

A beautiful, modern landing page for SensPa intelligent bidet covers with WhatsApp integration and custom wave animations.

## Features

- 🎨 **Modern Design**: Clean, professional design with gradient backgrounds and glassmorphism effects
- 🌊 **Custom Wave Animations**: Animated SVG waves for visual appeal
- 📱 **Fully Responsive**: Optimized for all devices (desktop, tablet, mobile)
- 💬 **WhatsApp Integration**: Direct WhatsApp links for easy customer contact
- ⚡ **Lightweight**: Pure HTML, CSS, and JavaScript - no heavy frameworks
- 🎯 **Conversion Focused**: Multiple call-to-action buttons leading to WhatsApp
- 🔄 **Smooth Animations**: Intersection Observer animations and hover effects
- 📊 **Performance Optimized**: Throttled scroll events and efficient animations

## Customization

### Changing WhatsApp Numbers

Update the WhatsApp links in `index.html`:

```html
<a href="https://wa.me/YOUR_PHONE_NUMBER?text=YOUR_MESSAGE"></a>
```

### Modifying Colors

Edit the CSS variables in `styles.css`:

```css
:root {
	--primary-color: #2563eb;
	--whatsapp-color: #25d366;
	--gradient-start: #667eea;
	--gradient-end: #764ba2;
}
```

### Adding Products

Duplicate the product card structure in `index.html`:

```html
<div class="product-card">
	<div class="product-image">
		<div class="product-badge">NEW</div>
		<!-- Product content -->
	</div>
</div>
```
